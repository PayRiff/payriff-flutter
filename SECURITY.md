# Security policy

## Reporting a vulnerability

Report security problems privately through GitHub: open this repository's
**Security** tab and choose **Report a vulnerability**. Please do not open a
public issue for a security problem.

Include:

- the SDK version, the platform (iOS or Android) and its OS version;
- what an attacker could do, and the steps to reproduce it;
- logs or a proof of concept, with keys, client secrets and card data removed.

We confirm each report and keep you informed while we fix it.

## Supported versions

Security fixes go into the latest 1.x release.
